# Sourced animals

37 skinned/rigid GLB assets for the runtime posing library in `gen/animal_3d/`.
The core Quaternius models are CC0; additional models retain their individual
CC0/CC BY licenses. Read CREDITS.md and licenses/ before redistribution.
Source hashes, revisions and modifications are recorded in the experiment's
prepared_asset_inventory.json and additional_asset_inventory.json. catalog.json
maps stable IDs to app resources and posing profiles. These models have not yet
replaced the production 2D generator.

The runtime API, pose studio and verification commands are described in
[`gen/animal_3d/README.md`](../../gen/animal_3d/README.md).
